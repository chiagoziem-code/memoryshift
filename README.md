# Memory Maker

Can you build me a prototype of an app for dyslexic learners that turns text inputs, photos, formulas, video, and audio inputs into different mnemonic formats of their choice? The app should include an onboarding calibration quiz to identify a starting mnemonic profile, and then let learners refine their preferences over time. Learners should have options to choose from different types of mnemonics, either matched to the array of options that closely fit them or suggesting outputs they like, with support for uploading different input formats.
